# Peck 1.4.0

A simpler everyday interface, improved typing controls, and tools for testing and sharing settings. These notes cover the changes since 1.1.

## Everyday use

- New bird app and menu-bar icon, with matching Basic and Advanced settings.
- Basic **Fast (2 ms), Medium (5 ms), Slow (15 ms)** controls. Existing saved values remain unchanged; other delays display Custom.
- Dedicated **⌃⌥V** current-focus shortcut alongside **⌃⌥⌘V** crosshair targeting. Shortcut conflicts preserve a working binding.
- Routine paste confirmations are **off by default**. Advanced offers optional Return/size rules behind a master switch.

## Delivery and tooling

- Cancellable waits, explicit key-hold and Return pacing, and serialized special keys.
- Filtering Escape handling and checks for detected target changes, unavailable input interception, and Secure Input.
- Strict keycode preflight, including unavailable keyboard layouts; empty input cannot trigger an appended Return.
- Optional experimental Vim bracketed paste, portable JSON profiles with import review, and calibration requiring three fresh exact matches per speed.
- Clear distinction between local received-keystroke trials and user-supplied remote results.

## Install and upgrade

Download **Peck-adhoc.zip** from the [release page](https://github.com/zeddy89/Peck/releases/tag/v1.4.0), unzip, and move Peck to Applications. Requires macOS 13 or later; Apple silicon and Intel are supported.

The package is **ad-hoc signed with hardened runtime, not notarized**. Follow [installation instructions](https://github.com/zeddy89/Peck/blob/v1.4.0/docs/install.md) if Gatekeeper blocks opening. Accessibility may need refreshing after the update; enable Input Monitoring if requested.

## Validation and limits

**123 tests passed, zero failures.** Release/fallback builds and strict verification of the extracted archive passed. See [verification](https://github.com/zeddy89/Peck/blob/v1.4.0/docs/verification.md) for actual UI checks and the local pre-release artifact record. Verify the published download against its release `SHA256SUMS` asset.

For ordinary vi/Vim typing, use `:set paste` when supported **and enter Insert mode with `i`**. The experimental bracketed-paste option requires compatible Vim/terminal behavior and is not a universal vi preparation mechanism.

A local match does not qualify vSphere or GLKVM. Fast 2 ms is not guaranteed for every target, browser-tab/guest focus cannot be pinned atomically, and already-posted input cannot be recalled. No GLKVM file-transfer or network adapter is included.
