These are unchanged image-generation outputs used as design references. They are **concept artwork, not screenshots of the implemented app**. Actual native controls, spacing, text, and icon renditions may differ.

The originals remain in the image-generation output directory. These copies were verified byte-for-byte by matching SHA-256 hashes. Icon renditions used by the app are separate generated assets; these originals have not been edited.

The implemented Basic and Advanced windows share the bird identity and visual styling; the menu-bar item uses the bird too. Use actual UI verification evidence in [verification](../verification.md) to assess the implementation rather than treating these concepts as screenshots.
